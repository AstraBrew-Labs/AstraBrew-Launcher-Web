---
title: 下载与安装
description: 选择适合自己的 Windows 发行版本和安装包。
---

## 选择版本

打开[版本下载](/zh/download?platform=windows)，选择 Windows。首次安装建议选**正式版（稳定版）**；测试版适合需要提前试用新功能的用户。

## 选择安装包

展开目标版本，查看它实际提供的文件。若同时提供 EXE 和 MSI，任选一种即可，不需要重复安装。运行下载的安装包，按安装向导完成操作。

## 完成安装

从 Windows 开始菜单打开星酿启动器，继续阅读[快速开始](/zh/docs)。如果下载页暂时没有显示版本，可以使用页面上的刷新按钮重新同步列表。

---
title: Download and installation
description: Choose a Windows release and install the launcher.
---

## Choose a release

Open [Downloads](/en/download?platform=windows) and select Windows. Choose a **stable release** for a first install. Beta releases are for trying upcoming changes.

## Choose an installer

Expand the release to see its available files. If both EXE and MSI installers are listed, choose one; you do not need both. Run the downloaded installer and follow its prompts.

## After installation

Open AstraBrew Launcher from the Windows Start menu and continue with [Quick start](/en/docs). If the download list is empty, use the refresh button on the downloads page to sync it again.

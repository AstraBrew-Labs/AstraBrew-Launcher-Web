## Before you start

This guide is for **Windows 10 version 1809 or later**. The macOS edition is not yet available; the Windows installer is not a Mac download.

New to the launcher? Follow [Download and installation](/en/docs/installation), then return here.

## Start SillyTavern

1. Open AstraBrew Launcher and go to the dashboard.
2. Check the tavern version under **Launch configuration**. The built-in version is a starting point for a first launch.
3. Select **Start service** and wait for the dashboard to show that the service is running.
4. Open the local address shown on your dashboard in a browser. Use the address and port from your own instance.

## If the browser cannot connect

Check that the service is still running and that the browser address uses the port shown in the dashboard. If startup failed, open the launcher's console and review the output for environment errors.
